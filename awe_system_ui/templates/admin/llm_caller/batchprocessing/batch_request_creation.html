Upload an Excel file (.xlsx) containing essays to process. The file should have:

  • A column containing the essay topics (default column name: "Essay Topic")

The output file will include these columns:

  • All original columns from the input file
  • Status - processing status
  • Score - evaluation score for each essay
  • Reasoning - explanation for the score
  • Error - any error messages (if applicable)
  • Raw Response - raw response from the LLM
  • Created At - date and time of creation
  • Started At - date and time of start
  • Ended At - date and time of end
